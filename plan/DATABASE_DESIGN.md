# Database Design: AgentForge Kernel Stack

## Overview

The AgentForge database is built on **PostgreSQL** with the **pgvector** extension. It serves as the persistent state engine for LangGraph workflows, the primary registry for the Toolsmith mechanism, and the semantic memory layer for tool discovery. It is designed for high-concurrency tool registration and hot-reloading without system restarts.

## Schema

```sql
-- Enable pgvector for semantic tool discovery
CREATE EXTENSION IF NOT EXISTS vector;

-- Tool Registry: Stores the "Hot-Reloadable" tool artifacts
CREATE TABLE tools (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(255) UNIQUE NOT NULL,
    description TEXT NOT NULL,
    version VARCHAR(50) NOT NULL,
    code_blob TEXT NOT NULL,           -- The actual Python logic
    pydantic_schema JSONB NOT NULL,    -- Input validation contract
    manifest JSONB NOT NULL,           -- Dependencies and metadata
    content_hash TEXT UNIQUE NOT NULL, -- Merkle-style hash for integrity
    embedding VECTOR(1536),            -- Vectorized docstring for RAG
    reliability_score FLOAT DEFAULT 0.0, -- Probabilistic Reliability Bound (PRB)
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    is_active BOOLEAN DEFAULT TRUE
);

-- Tool Validation Results: Evidence-Based Validation (EBV)
CREATE TABLE tool_validations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tool_id UUID REFERENCES tools(id),
    test_suite_json JSONB NOT NULL,    -- Synthetic tests run by Forge
    passed BOOLEAN NOT NULL,
    logs TEXT,
    validated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Agent State: LangGraph Persistence
CREATE TABLE agent_checkpoints (
    thread_id TEXT NOT NULL,
    checkpoint_id TEXT NOT NULL,
    parent_id TEXT,
    checkpoint BYTEA NOT NULL,         -- Binary state of the graph
    metadata JSONB,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (thread_id, checkpoint_id)
);

-- Circuit Breakers: Safety Rails and Resource Budgeting
CREATE TABLE execution_limits (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    thread_id TEXT UNIQUE NOT NULL,
    max_depth INTEGER DEFAULT 10,
    current_depth INTEGER DEFAULT 0,
    token_budget INTEGER DEFAULT 50000,
    used_tokens INTEGER DEFAULT 0,
    is_locked BOOLEAN DEFAULT FALSE
);
```

## Entities

| Entity | Description | Key Fields |
|--------|-------------|------------|
| **Tool** | The core artifact generated by the Forge Node. | `content_hash`, `code_blob`, `embedding` |
| **Validation** | Records of EBV (Evidence-Based Validation) test passes. | `tool_id`, `passed`, `test_suite_json` |
| **Checkpoint** | Persistent state for LangGraph multi-retry loops. | `thread_id`, `checkpoint`, `checkpoint_id` |
| **Limit** | Hierarchical circuit breakers and budget tracking. | `thread_id`, `max_depth`, `used_tokens` |

## Relationships

- **Tools to Validations (1:N):** A single tool artifact may undergo multiple validation attempts or regression tests as the Forge evolves.
- **Checkpoints to Tools (N:M):** Via the Tool Gateway, multiple agent threads can invoke the same registered tool artifact simultaneously.
- **Execution Limits to Checkpoints (1:1):** Each unique LangGraph thread is bound to a specific safety profile to prevent recursive blowup.

## Indexes

- **Semantic Search Index:** `CREATE INDEX tool_vector_idx ON tools USING ivfflat (embedding vector_cosine_ops);` - Enables the "Semantic Skill Index" for RAG-based tool discovery.
- **Integrity Index:** `CREATE UNIQUE INDEX idx_tool_hash ON tools (content_hash);` - Prevents duplicate tool generation and ensures content-addressable security.
- **State Lookup:** `CREATE INDEX idx_checkpoint_thread ON agent_checkpoints (thread_id, created_at DESC);` - Optimizes for rapid state recovery in retry loops.

## Migrations

Migration strategy: **Atomic Schema Evolution**. 
1. **Tool Versioning:** Tools are never updated in place; new versions generate new rows with new `content_hash` values to prevent breaking active sessions.
2. **Hot-Reloading:** The Tool Gateway polls the `tools` table for `is_active = TRUE` and `created_at > last_poll` to inject new artifacts into the runtime.
3. **Tooling:** Use `alembic` (Python) or `atlas` for schema versioning, ensuring the `pgvector` extension is pre-provisioned in the Postgres container.
